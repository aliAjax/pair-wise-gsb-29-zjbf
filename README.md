# 社区团购装车台

- 行业：物流
- 技术栈：Vue3、Vite、TypeScript、Element Plus
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

晚间生鲜团购到站后的装车台模拟：

- 社区订单记录批次、温区（冷藏/常温）和承诺时段，统一进入候装区
- 骑手记录班次、泊位、保温袋及容量，袋子可标记污染/消毒
- 冷藏件只能装未污染的保温袋；容量不足或无干净袋子时留在候装区并写明滞留原因
- 骑手请假后泊位当天释放，同班次在岗骑手可接管其未出发订单，交接记录前后责任人和已装数量
- 数据保存在浏览器 localStorage，重开页面可在「当日核对」中复查当天装车件数与转单交接结果
