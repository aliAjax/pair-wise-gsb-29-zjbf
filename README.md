# 城市末端配送模拟 · 晚间生鲜装车台

- 行业：物流（社区生鲜团购末端配送）
- 技术栈：Vue3、Vite、TypeScript、Element Plus
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

## 业务闭环

晚间生鲜团购到站后，装车台完成订单登记、装袋校验、骑手出发与请假交接：

- **社区订单**：记录批次号、社区、温区（冷藏/常温）、承诺时段、件数，到站先进候装区。
- **骑手排班**：记录班次、泊位、保温袋是否未污染、保温袋容量。
- **装车校验**：
  - 冷藏件只能装入未污染保温袋（袋中装过常温件即标记污染，需清洗/更换后才能恢复）；
  - 同一保温袋不允许冷藏件与常温件混装；
  - 容量不足或袋被污染时，订单留在候装区并写明拒收原因；
  - 支持逐单装车与“智能配载”批量配载。
- **出发**：骑手携已装订单出发离站，出发后订单不可再转单。
- **请假交接**：同班次在岗骑手可接管请假者未出发订单；接管袋装不下的部分退回候装区并写明原因；原泊位当天释放；交接记录前后责任人、交接已装数量与退回数量。
- **当日核对（重开）**：数据按日期保存在浏览器 localStorage，当天重开页面可核对装车结果、候装滞留原因与转单结果；跨天自动开启新作业日。
